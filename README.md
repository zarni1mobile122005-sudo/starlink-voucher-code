### 🛠 Description
ဒီ Tool က Starlink Voucher code တွေကို အလိုအလျောက် ခန့်မှန်းရှာဖွေပေးတဲ့ Simulation tool တစ်ခု ဖြစ်ပါတယ်။ အမြင်ပိုင်းဆိုင်ရာမှာ **Loading Spinner** တွေ၊ **Search History** တွေနဲ့ မိုက်မိုက်လေး ဒီဇိုင်းထုတ်ထားပါတယ်။

### 🚀 Features
* 🌀 **Dynamic Loading:** အဝိုင်းလည်ပြီး ရှာဖွေနေတဲ့ Realistic animation ပါဝင်ခြင်း။
* 📜 **Live History:** ရှာတွေ့သမျှ Code တွေကို အောက်မှာ စာရင်းလိုက် ပြပေးခြင်း။
* ⚡ **Fast & Lightweight:** Termux မှာ အပေါ့ပါးဆုံး run နိုင်ခြင်း။
